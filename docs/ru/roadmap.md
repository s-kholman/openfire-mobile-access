# Дорожная карта

## Этап 0 — Проверка технической возможности

- Подтвердить требования к сборке плагинов Openfire 5.1.1 и совместимость с Java 21.
- Подтвердить точный путь записи пароля через `DefaultAuthProvider`.
- Проверить схему таблицы `ofUser` в установленной PostgreSQL.
- Проверить совместную работу LDAP-профиля и локальной парольной строки одного пользователя.
- Подготовить процедуру отката.

Критерий завершения: согласованное техническое решение о безопасном способе записи локальных учётных данных.

## Этап 1 — Каркас плагина

- Maven-сборка.
- Дескриптор плагина Openfire.
- Класс жизненного цикла плагина.
- Пункт меню административной консоли.
- Страница просмотра без изменения данных.
- Базовая инфраструктура модульных тестов.

Критерий завершения: плагин устанавливается и удаляется на Openfire 5.1.1 без изменения данных.

## Этап 2 — Проверка LDAP-пользователя

- Поиск по короткому логину.
- Точная проверка `sAMAccountName`.
- Проверка разрешённой группы.
- Отображение данных пользователя и статуса мобильного доступа без записи в базу.

Критерий завершения: пользователь `s_kholman` находится и проходит проверку без изменения базы данных.

## Этап 3 — Управление учётными данными

- Создание минимального локального контейнера при его отсутствии.
- Установка или замена пароля через согласованный API Openfire.
- Очистка только локальных парольных данных при отзыве.
- Транзакции и идемпотентность операций.

Критерий завершения: Android входит с локальным паролем, а Windows Spark продолжает входить через Kerberos.

## Этап 4 — Аудит и усиление безопасности

- Постоянная таблица аудита.
- CSRF-защита.
- Усиленная проверка ввода и вывода.
- Проверка совместимости конфигурации провайдеров.
- Понятные ошибки без раскрытия чувствительной информации.
- Интеграционные тесты и контрольный список проверки.

Критерий завершения: первая контролируемая тестовая версия.

## Этап 5 — Эксплуатационный выпуск

- Инструкция установки.
- Инструкция обновления и отката.
- Руководство администратора.
- Версионируемый артефакт сборки.
- GitHub Actions для автоматической сборки.

Критерий завершения: версия `0.1.0`, пригодная для установки на тестовый сервер.

## Возможные последующие функции

- самостоятельная смена пароля;
- токены регистрации и QR-коды;
- ограниченный срок мобильного доступа;
- второй фактор;
- интеграция с Laravel;
- доставка через SMS или Telegram;
- регистрация устройств и политика доступа.
