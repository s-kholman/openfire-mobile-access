# Требования к продукту

## Назначение

Openfire Mobile Access — административный плагин для Openfire 5.1.1, который позволяет выдавать локальные мобильные учётные данные пользователям, чья идентичность, профиль и членство в группах предоставляются Active Directory через LDAP.

## Целевая модель аутентификации

- Доменные компьютеры Windows входят в Openfire через Kerberos/GSSAPI.
- LDAP используется только как источник пользователей, групп и vCard.
- Пароли LDAP не принимаются Openfire.
- Мобильные XMPP-клиенты используют отдельный локальный пароль Openfire.
- Локальный логин должен строго совпадать с `sAMAccountName` в AD.
- Windows- и мобильная сессии используют один и тот же XMPP JID.

## Обязательные функциональные требования

1. Поиск пользователя только по короткому логину.
2. Подтверждение существования соответствующей LDAP-записи.
3. Проверка точного совпадения запрошенного логина и LDAP-атрибута `sAMAccountName`.
4. Проверка членства в настроенной AD-группе мобильного доступа.
5. Отображение наличия или отсутствия локальных мобильных учётных данных.
6. Создание или замена локального мобильного пароля без изменения LDAP-данных.
7. Отзыв локальных мобильных учётных данных без удаления LDAP-пользователя.
8. Журналирование всех административных операций.
9. Запрет на запись открытых паролей в журнал или постоянное хранилище.
10. Сохранение Kerberos-аутентификации после создания или отзыва мобильных учётных данных.

## Исходная среда

- Openfire: 5.1.1
- Java: 21
- Операционная система: Ubuntu 24.04 LTS
- База данных: PostgreSQL
- XMPP-домен: `openfire.krimm.ru`
- Домен Active Directory: `krimm.local`
- LDAP-группа пользователей: `CN=Openfire-Users,OU=OpenFire,DC=krimm,DC=local`

## Объём первой версии

Первая версия предназначена только для администратора и включает:

- страницу в административной консоли Openfire;
- проверку пользователя в LDAP;
- проверку разрешённой группы;
- отображение статуса локальных учётных данных;
- создание или замену пароля;
- отзыв доступа;
- аудит операций;
- защиту от CSRF;
- инструкции по установке и откату.

## Не входит в первую версию

- пользовательский кабинет самообслуживания;
- доставка через SMS или Telegram;
- двухфакторная аутентификация;
- QR-код для настройки клиента;
- срок действия пароля;
- интеграция с Laravel;
- привязка к устройству.
