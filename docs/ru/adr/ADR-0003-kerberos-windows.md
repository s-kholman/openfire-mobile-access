# ADR-0003: Kerberos для управляемых Windows-клиентов

- Статус: Принято
- Дата: 2026-07-18

## Контекст

Компьютеры Windows, включённые в домен, могут проходить прозрачную аутентификацию без повторного ввода пароля.

## Решение

Использовать SASL GSSAPI/Kerberos как основной механизм аутентификации управляемых Windows-клиентов Spark.

## Последствия

Работа SSO зависит от правильных DNS, SPN, синхронизации времени, защиты keytab и конфигурации клиентов. Kerberos не используется как основной механизм входа с мобильных устройств.
