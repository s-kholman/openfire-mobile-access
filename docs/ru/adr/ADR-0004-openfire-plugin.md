# ADR-0004: Расширение Openfire через плагин

- Статус: Принято
- Дата: 2026-07-18

## Контекст

Решению нужны административный интерфейс, проверка доступа через LDAP, управление мобильными паролями и аудит без сопровождения собственной модифицированной сборки Openfire.

## Решение

Реализовать функциональность отдельным плагином Openfire и по возможности использовать поддерживаемые сервисы и точки расширения Openfire.

## Последствия

Ядро Openfire остаётся обновляемым. Совместимость необходимо проверять с поддерживаемыми версиями Openfire. Прямой доступ к базе изолируется и применяется только при отсутствии подходящего API после отдельного ревью и тестирования.
