# ADR-0002: Отдельные локальные учётные данные для мобильного доступа

- Статус: Принято
- Дата: 2026-07-18

## Контекст

Личные мобильные устройства должны подключаться к Openfire без передачи пользователю или приложению пароля Active Directory либо VPN.

## Решение

Для того же имени пользователя хранится отдельный локальный пароль Openfire. Создание, смена и отзыв пароля выполняются через плагин и API Openfire.

## Последствия

Дублирующий мобильный пользователь не создаётся. Компрометация мобильного пароля напрямую не раскрывает пароль AD. Управление жизненным циклом пароля и аудит становятся обязанностями плагина.
