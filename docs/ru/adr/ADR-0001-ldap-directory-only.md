# ADR-0001: LDAP используется только как каталог

- Статус: Принято
- Дата: 2026-07-18

## Контекст

Openfire должен получать из Active Directory имена пользователей, группы, отображаемые имена и электронную почту, но пароль AD не должен использоваться на личных мобильных устройствах.

## Решение

Использовать только LDAP-провайдеры пользователей, групп и vCard. В целевой архитектуре не использовать `LDAPAuthProvider`.

## Последствия

LDAP остаётся главным источником идентичности и разрешения доступа. Windows использует Kerberos. Для мобильных клиентов требуется отдельный локальный пароль. Плагин не изменяет данные каталога.
